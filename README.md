A single short text written to slow its reader down: starlight that left home a thousand years ago, still arriving, cool and unhurried. The program writes that text to `entry.txt` — nothing else, no network, the same bytes every run.

## Run it

```sh
node main.ts
```

By default it writes to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to choose another directory.
